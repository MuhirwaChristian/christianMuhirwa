# Christian MUHIRWA – Personal Portfolio

This project is a personal portfolio website for **Christian MUHIRWA**, an Information Technology professional specializing in communication, graphic design, IT support, photography, and digital content management. The website presents professional information, education, skills, and project experience, including work on the SUNCASA Project. It is designed using HTML and CSS with a responsive layout that can be viewed on desktops, tablets, and mobile devices.

## Features

* **About Me Section** – Provides personal and professional information about Christian MUHIRWA, including his position, location, gender, level, and marital status.
* **Profile Section** – Displays the profile photo and a brief professional introduction.
* **Project Section** – Presents the SUNCASA Project, including its description, role, deliverables, duration, and completion status.
* **Education Section** – Displays educational background, including the Advanced Diploma in Information Technology from IPRC HUYE and Advanced Level education from ACEJ/KARAMA.
* **Skills Section** – Highlights skills in Graphic Design, Communication, IT Support, Photography, and Digital Content Management.
* **Contact Section** – Provides contact information and a way for visitors to get in touch.
* **Responsive Design** – The website adapts to desktop, tablet, and mobile screen sizes.
* **Navigation Menu** – Allows users to quickly navigate between the different sections of the portfolio.
* **Professional Design** – Uses a modern green, white, and dark color scheme with interactive hover effects.

## How to Run This Project

The project is a static website and does not require a web server or database.

The website can be accessed locally by downloading or cloning the project repository and opening the `index.html` file in a web browser.

The project can also be hosted online using services such as GitHub Pages.

### Prerequisites

Before running the project, users need:

* A computer or smartphone.
* A modern web browser such as Google Chrome, Microsoft Edge, Firefox, or Safari.
* Git, if they want to clone the project from GitHub.
* An internet connection is recommended because the website uses Google Fonts.

No additional programming packages or frameworks are required.

### Installation

#### 1. Clone the repository

Open a terminal or command prompt and run:

```bash
git clone  https://muhirwachristian.github.io/christianMuhirwa/
```

#### 2. Enter the project folder

```bash
cd documents
cd potifolio
cd christianMuhirwa
cd christianMuhirwa

```

#### 3. Open the project

Open the `index.html` file in your preferred web browser.

Alternatively, if you are using Visual Studio Code, you can open the project folder and use the **Live Server** extension to run the website.

#### 4. Access the website

When running locally, the website can normally be accessed through a local address such as:

```text
file:///C:/Users/user/Documents/potifolio/christianMuhirwa/christianMuhirwa/index.html
```

The exact address may depend on the development tool being used.

## Deployment

The portfolio can be deployed using **GitHub Pages**.

After pushing the project to GitHub:

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, select the main branch.
5. Select the root folder `/`.
6. Save the settings.
7. GitHub will generate a public website link.

The project can then be accessed by anyone using the generated GitHub Pages URL.
